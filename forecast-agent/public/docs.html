API guide

Send sales, stock levels or CSV exports from any system, and read forecasts and reorder suggestions back. An admin creates API keys in Connections → API keys. The API must be switched on for your company.

Authentication

Send the key as a bearer token over HTTPS:

Authorization: Bearer fa_live_xxxxxxxx_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Each key is limited to 120 calls a minute (you'll get 429 with Retry-After if you go over). Each key has its own permissions: sales:write, inventory:write, forecasts:read.

POST /v1/sales

Up to 5,000 rows per call. Dates can be days (2026-11-15) or months (2026-11). Rows are added up by month for each product × location × region.

curl -X POST https://forecast-agent.marlon615.workers.dev/v1/sales \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"mode":"replace_months","rows":[
        {"date":"2026-10-03","product":"Mango Juice","location":"Store 12","region":"West","amount":250.00,"quantity":10}
      ]}'

mode can be:

  • replace_months (default): each call holds the complete figures for every month it mentions, for every product and location. Those months replace what was stored, so re-sending is safe.
  • add: figures are added to what's already stored.

The answer is 202. The accuracy test, and the forecast if it's switched on, then update in the background (see /v1/jobs).

POST /v1/files: HTTPS file drop

Send a CSV export as the request body (up to 20 MB; split bigger exports). The columns are recognised the same way as an upload. Name them in the query string if needed:

curl -X POST "https://forecast-agent.marlon615.workers.dev/v1/files?date=Order%20Date&product=SKU&location=Store&amount=Net%20Sales&units=Qty&dateOrder=mdy" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: text/csv" --data-binary @sales.csv

The same mode options apply; the default replaces the months in the file. You can also have the service pull a file from a web address every night: add a "File from a web address" connection.

SFTP isn't offered: the service runs on Cloudflare, which doesn't accept SFTP connections. Most schedulers that can drop a file over SFTP can also send it to this HTTPS endpoint.

POST /v1/inventory

{"replace": false, "items": [
  {"product":"Mango Juice","location":"Store 12","on_hand":42,"on_order":0,"lead_time_days":10,"case_pack":12,"min_order":24,"unit_cost":12.5}
]}

Up to 20,000 items per call. Product and location names must match your sales data. Reorder suggestions update automatically.

GET /v1/forecasts

?view=total|product|location|region and optionally &upload=main|api|<id>. The default is main: your newest connected or API data, or the one chosen in Stock settings.

GET /v1/reorder

Reorder suggestions:

  • status;
  • on hand and on order;
  • daily demand;
  • days of cover;
  • safety stock;
  • reorder point;
  • suggested quantity and order value.

GET /v1/jobs

The latest background jobs (imports, accuracy tests, forecasts, syncs), with progress and any error.

Errors

  • 400: the request needs fixing; the message says what.
  • 401: missing or invalid key.
  • 402: the feature isn't switched on for your company.
  • 403: the key lacks a permission, or the account is switched off.
  • 413: too big.
  • 429: slow down.
